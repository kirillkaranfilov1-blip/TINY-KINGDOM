# Tiny Kingdom

Прототип градостроительной стратегии на Godot 4 с объёмным средневековым поселением и интерфейсом управления городом.

## Запуск

Откройте папку проекта в Godot и запустите `scenes/main.tscn`.

## Управление

- Выберите постройку на левой панели и нажмите по свободной клетке поселения.
- Источники ресурсов: ферма производит еду, лесопилка — дерево, каменоломня — камень, рынок приносит золото; жители также платят налоги.
- Жители потребляют еду; при достаточном запасе и свободном жилье население растёт.
- Кнопка «Снести» удаляет постройку и возвращает часть материалов.
- Пробел ставит симуляцию на паузу, клавиши `1` и `2` меняют скорость времени.
- Колесо мыши приближает и отдаляет камеру.

## Структура

- `project.godot` — настройки проекта и окна.
- `scenes/main.tscn` — главная 3D-сцена.
- `scripts/game_3d.gd` — процедурная деревня, камера, интерфейс, строительство и симуляция.
- `scripts/game.gd` — предыдущий 2D-прототип.
